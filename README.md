# College Final Grade Calculator

A sleek, real-world utility web application hosted on GitHub Pages that helps students calculate the exact score they need on a final exam to achieve their target course grade.

## 🚀 Live Demo
Visit the live site here: `https://timbeely.github.io/gradeCalc/`

## ✨ Features
* Dynamic Row Generation: Instantly add or delete custom entries for Homework, Assignments, Quizzes, and Midterms.
* Flexible Weighting Modes: Toggle individual weights per item or distribute an overarching category weight evenly across entries.
* Real-time Local Caching: Automatically backs up all entered scores, checkboxes, and weights to the browser's persistent memory so no data is lost upon refresh.
* Flat Extra Credit Integration: Factors in overall bonus points directly to accurately reflect real-world grading policies.
* Midnight Matte Theme: Includes a responsive Light/Dark Mode toggle designed with strict high-contrast legibility colors.
* Live Calculation Safety: Processes mathematical values silently as you type, enforcing a strict 100% total weight validation limit upon calculation clicks to prevent errors.

## 🛠️ Built With
* HTML5: Semantic structure and layout baseline.
* CSS3: Modern, responsive card-style design utilizing dynamic theme variables.
* JavaScript (ES6): Dynamic DOM rendering, robust error checking, storage tracking, and algebraic grading logic.
